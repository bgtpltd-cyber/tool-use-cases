新着・話題のツール

ここ6週間に出た、builderにとって重要なAIツールのリリースと大型アップデートです。それぞれに日付、公式発表へのリンク、合うユースケースを付けています。

最終更新：2026年10月22日

10月20日

Mistral Voxtral 3

Mistralの新しいspeech-to-textとtext-to-speechのモデルに加え、電話やWebでリアルタイムに動くvoice agentを作るためのSDK。Mistral API（EU内ホスティングも選べる）またはセルフホストで使えます。

ユースケース：音声・text-to-speechにおすすめのAI · 出典

10月15日

Kling 4.0

Kuaishouの新しい動画モデル。1回で最長30秒のクリップを生成でき、速い動きやカメラワークが安定し、1つのタスクで最大15個の参照素材と10個のキーフレームを使えます。

ユースケース：動画・YouTubeにおすすめのAI · 出典

10月15日

Meta Muse Spark Open

coding・agent用途のMetaのopen weightsモデル（816Bパラメータ、42Bアクティブ、1Mトークンのコンテキスト）。Metaは2台のMac Studioで動かしていますが、多くの人にはホスティングされたAPIが現実的です。

ユースケース：AIをローカルで動かすためのおすすめツール · 出典

10月7日

Claude Haiku 5.5

Anthropicで最も安くて速いモデル。サポートbot、要約、codingのsubagentなど、大量にこなす処理向け。Anthropicによると、Haiku 4.5より約75%安く動かせます。

ユースケース：チャットボット・RAGにおすすめのAI · 出典

10月6日

Nano Banana 2.1 (Google)

Googleの画像生成・編集モデルのアップデート。編集の精度、キャラクターの一貫性、画像内の文字が改善。Geminiアプリ、AI Studio、Gemini API、Flow、Stitchで使えます。

ユースケース：画像生成におすすめのAI · 出典

10月1日

GitHub Copilot dynamic workflows

複数のagentを使う作業をコードで定義（並列ステップ、subagent同士の相互チェック、レビュー用のチェックポイント）。Copilot CLI、Copilotアプリ、Copilot SDKで利用可能。Public preview、全プラン対象。

ユースケース：おすすめのAI coding agent · 出典

9月30日

HeyGen Video

HeyGen初の汎用動画モデル。テキスト、画像、参照メディアから5〜15秒のクリップを作り、セリフと音も一緒に生成します。HeyGen API経由で利用できます。

ユースケース：動画・YouTubeにおすすめのAI · 出典

9月29日

GPT-6.1 Sol

OpenAIがDevDayで発表したGPT-6 Solのアップグレード。agenticなcoding、computer use、プロの仕事に重点。OpenAIによると、ずっと安い価格でGPT-6 Astraに近い性能です。

ユースケース：おすすめのAI coding agent · 出典

9月29日

OpenAI Agents API: computer use

Agents APIがcomputer useでソフトウェアを操作できるようになり、Codexのmulti-agent機能、tool search、コンテキストの圧縮も自分のアプリで使えます。インフラはOpenAIが運用します。

ユースケース：おすすめのAI agent framework · 出典

9月28日

Claude Sonnet 5.5

Anthropicのより速く安いSonnet。範囲のはっきりした日常タスクとバグ修正が得意。Sonnet 5より30%以上速く、価格は同じ100万トークンあたり$2/$10。

ユースケース：壊れたコードやエラーの修正におすすめのAI · 出典

9月24日

Lovable: free chat

Lovableとのチャットが1日の無料枠内で無料に。機能の計画、アプリのコードやデータベースについての質問、ローンチ用の文章の下書きができます。ビルドには引き続きクレジットを使います。

ユースケース：Vibe codingにおすすめのAI · 出典

9月10日

Cursor Projects

機能追加や移行のような大きな作業向けのベータ。coordinator agentがクラウドで動き、作業を計画して多数のsubagentに割り振り、共有コンテキストを保ち続けます。

ユースケース：おすすめのAI coding agent · 出典

以前の掲載

今回の更新より前に紹介していたリリースです。もう新着ではありませんが、知っておく価値があります。

  • Claude Code — Anthropicのターミナル向けcoding agent。いま最も話題の開発ツールの1つです。
  • OpenAI Codex — OpenAIが再始動させたcoding agent、Codex（クラウド + CLI）。
  • Google Veo — Googleの動画モデル。同期した音声も生成できるようになりました。
  • Manus — 複数ステップのタスクをこなしてバズった汎用の自律型agent。
  • Lovable — 急成長しているpromptベースのアプリビルダー。
  • Gemini Notebook (formerly NotebookLM) — 音声の要約（Audio Overviews）で、リサーチメモをポッドキャストに変えました。
  • Kling — AI動画生成の有力な競合。
  • DeepSeek — 市場の価格を揺るがしたopen weightsの推論モデル。
  • Model Context Protocol — ほとんどのagentツールがツール利用のために対応しているオープンなプロトコル。
  • Devin Desktop (formerly Windsurf) — Cursorと真っ向から競うagenticなエディタ。
