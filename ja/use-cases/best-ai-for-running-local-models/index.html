AIをローカルで動かすためのおすすめツール

自分のマシンで、プライベートに、従量課金なしで使えるAI。

スポンサー

あなたのツールをここに

この注目枠は、このユースケースに本当に合うツールを作っている方向けです。必ず明記し、編集部のおすすめとは常に分けて表示します。

メールでスポンサーを申し込む

おすすめ

  1. 1. Ollama

    オープンなモデル（Llama、Qwenなど）をコマンド1つでローカル実行。

    ひとこと： コマンド1つでオープンなモデルを取得して実行。始めるならこれが一番簡単です。

  2. 2. DeepSeek

    中国のAIラボ。強力で安価なopen weightsの推論モデルを公開。

    ひとこと： ローカルで動かすことも、APIで安く使うこともできる強力なopen weightsモデル。

  3. 3. OpenCode

    ターミナル、デスクトップ、IDEで使えるオープンソース（MIT）のコーディングagent。ローカルモデルを含む75以上のモデルプロバイダに対応。

    ひとこと： Ollamaで動かしているモデルにつなげば、オフラインのコーディングagentになります。

  4. 4. Stable Diffusion

    ローカルで動かせるオープンな画像モデルのファミリー（ComfyUIなどで利用）。

    ひとこと： ローカル画像モデルの定番エコシステム。

おすすめは編集部の判断で、掲載料は受け取っていません。料金や機能はよく変わるので、各ツールの公式サイトで確認してください。
