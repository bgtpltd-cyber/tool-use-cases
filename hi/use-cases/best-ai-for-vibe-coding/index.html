Vibe coding के लिए बेस्ट AI

बताइए, चलाइए, सुधारिए। ऐसे टूल्स जिनसे आप ज़्यादातर बातचीत करके ही सॉफ़्टवेयर बना लेते हैं।

Sponsored

आपका टूल यहाँ

यह फ़ीचर्ड स्लॉट उन टूल बनाने वालों के लिए है जिनका टूल इस use case में सच में फ़िट बैठता है। हमेशा साफ़ तौर पर लेबल किया जाता है और हमारी पसंद से हमेशा अलग रहता है।

स्पॉन्सर करने के लिए ईमेल करें

हमारी पसंद

  1. 1. Cursor

    AI-first कोड एडिटर (VS Code का fork), जिसमें chat, inline edits और agent mode है।

    हमारी राय: डिफ़ॉल्ट चॉइस: असली codebase और एडिटर आपके पास रहता है, पर ज़्यादातर टाइपिंग AI करता है।

  2. 2. Lovable

    Prompt से full-stack वेब ऐप बनाने वाला builder, Supabase integration के साथ।

    हमारी राय: आइडिया से auth और database वाले चालू वेब ऐप तक पहुँचने का सबसे तेज़ रास्ता, बिना किसी setup के।

  3. 3. v0

    Vercel का AI app/UI builder, जो prompts से React + Tailwind ऐप्स बनाता है।

    हमारी राय: तब बेस्ट जब आपको जल्दी से polished React/Next.js UI चाहिए और deploy Vercel पर करना है।

  4. 4. Replit Agent

    ब्राउज़र वाला IDE, जिसका agent एक prompt से ऐप बनाकर deploy भी कर देता है।

    हमारी राय: Hosting समेत सब कुछ ब्राउज़र में — जल्दी बनने और शेयर होने वाले prototypes के लिए अच्छा।

  5. 5. Bolt.new

    StackBlitz का ब्राउज़र में चलने वाला prompt-to-app builder।

    हमारी राय: Lovable जैसा ही; एक ही टैब में full-stack demo खड़ा करने के लिए बढ़िया।

  6. 6. Windsurf

    AI कोड एडिटर, जिसमें 'Cascade' नाम का agentic असिस्टेंट है।

    हमारी राय: दमदार agent वाला Cursor का विकल्प; अगर Cursor जम नहीं रहा तो एक बार ज़रूर आज़माएँ।

ये पसंद हमारी अपनी है, इसके लिए किसी ने पैसे नहीं दिए। कीमतें और फ़ीचर्स अक्सर बदलते रहते हैं — हर टूल की ऑफ़िशियल साइट ज़रूर चेक करें।
