किस काम के लिए कौन-सा AI टूल।

Tool Use Cases AI टूल्स की एक डायरेक्टरी है, जिसे इस हिसाब से बनाया गया है कि आप कौन-सा काम करना चाहते हैं — vibe coders, builders और AI के साथ कुछ भी ship करने वाले हर किसी के लिए।

Use cases

Vibe coding के लिए बेस्ट AI

बताइए, चलाइए, सुधारिए। ऐसे टूल्स जिनसे आप ज़्यादातर बातचीत करके ही सॉफ़्टवेयर बना लेते हैं।

Cursor, Lovable, v0, Replit Agent, Bolt.new, Devin Desktop (formerly Windsurf)

बेस्ट AI coding agents

ऐसे agents जो टास्क लेते हैं, कई फ़ाइलें एडिट करते हैं, commands चलाते हैं और diff के साथ लौटते हैं।

Claude Code, Cursor, OpenAI Codex, GitHub Copilot, Devin, OpenCode

टूटा कोड और errors ठीक करने के लिए बेस्ट AI

Stack trace पेस्ट करें, fix पाएँ। ऐसे टूल्स जो सिर्फ़ कोड बनाने में नहीं, debugging में भी अच्छे हैं।

Claude, Cursor, ChatGPT, GitHub Copilot, Sentry (Seer), Claude Code

गेम prototyping के लिए बेस्ट AI

खेलने लायक आइडिया जल्दी स्क्रीन पर लाएँ — कोड, art, 3D और म्यूज़िक।

Rosebud AI, Cursor, Scenario, Meshy, Suno, ElevenLabs

वीडियो और YouTube के लिए बेस्ट AI

Footage बनाएँ, तेज़ी से एडिट करें, voice डालें और Shorts काटें।

Descript, Runway, Google Veo, ElevenLabs, OpusClip, CapCut, HeyGen

बेस्ट AI writing assistants

Drafting, editing और rewriting — docs, blog posts, READMEs, emails।

Claude, ChatGPT, Notion AI, Grammarly, Gemini

रिसर्च के लिए बेस्ट AI

Sources ढूँढें, पढ़ें और summarize करें — ऐसे citations के साथ जिन्हें आप चेक कर सकें।

Perplexity, Gemini Notebook (formerly NotebookLM), ChatGPT, Gemini, Elicit, Grok

Image generation के लिए बेस्ट AI

Midjourney, ChatGPT Images, Ideogram, FLUX (Black Forest Labs), Adobe Firefly, Stable Diffusion

नए लॉन्च और ट्रेंडिंग

  • Replit Cloud Agents for company codebases (27 अक्टूबर) — Replit के Cloud Agents अब आपकी company के मौजूदा GitHub या GitLab repos पर काम करते हैं। team का कोई भी व्यक्ति बदलाव बताता है, agent उसे चल रहे app में test करता है और engineers के review के लिए screenshots और video के साथ pull request खोलता है। Pro और Enterprise plans पर।
  • GPT-6.1 Terra in GitHub Copilot (26 अक्टूबर) — OpenAI का सबसे नया model अब GitHub Copilot में सबके लिए उपलब्ध है, जो रोज़ की agentic coding और terminal के काम के लिए बना है और GPT-6.1 Sol से कम लागत पर चलता है। Copilot Pro, Pro+, Max, Business और Enterprise पर, धीरे-धीरे rollout हो रहा है।
  • Replit Monitoring Agent (23 अक्टूबर) — Replit का Agent अब published app के alerts पर background में नज़र रखता है, production की समस्याओं की जाँच करता है और fix को test करता है। fix आप खुद review करके publish करते हैं, जब तक आप experimental Auto-republish setting चालू न करें।
  • Cursor Agent SDK (20 अक्टूबर) — अपना agent code के एक folder के रूप में बनाएँ (prompt, typed tools, skills और MCP connections), evals से test करें और Cursor या अपने servers पर deploy करें। agents GitHub, GitLab, Bitbucket, Slack, webhook या cron events पर चालू हो सकते हैं।
  • Lovable: creates your Supabase project (20 अक्टूबर) — Lovable अब बिना backend वाले app के लिए Supabase project बनाकर उसे जोड़ देता है। organization और region आप चुनते हैं (region बाद में नहीं बदला जा सकता), और Supabase उस project का बिल आपके अपने account में भेजता है।
