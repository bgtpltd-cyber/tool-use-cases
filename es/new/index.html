Lanzamientos y tendencias

Lanzamientos y actualizaciones importantes de herramientas de IA de las últimas seis semanas que importan a quienes construyen. Cada uno lleva su fecha, el enlace al anuncio oficial y el caso de uso en el que encaja.

Última actualización: 26 de octubre de 2026

23 de octubre

Replit Monitoring Agent

El Agent de Replit ahora vigila en segundo plano las alertas de una app publicada, investiga problemas en producción y prueba una corrección. Tú revisas y publicas la corrección, salvo que actives la opción experimental Auto-republish.

Caso de uso: Mejor IA para arreglar código roto y errores · Fuente

20 de octubre

Lovable: creates your Supabase project

Lovable ahora crea un proyecto de Supabase para una app sin backend y lo conecta por ti. Eliges la organización y la región (la región no se puede cambiar después), y Supabase factura el proyecto a tu propia cuenta.

Caso de uso: Mejor IA para vibe coding · Fuente

20 de octubre

Mistral Voxtral 3

Nuevos modelos de speech-to-text y text-to-speech de Mistral, más un SDK de agentes de voz en tiempo real para teléfono y web. Por la API de Mistral (con opción alojada en la UE) o self-hosted.

Caso de uso: Mejor IA de voz y texto a voz · Fuente

15 de octubre

Kling 4.0

Nuevo modelo de video de Kuaishou: clips de hasta 30 segundos de una sola vez, movimientos rápidos y de cámara más estables, y hasta 15 referencias y 10 keyframes por tarea.

Caso de uso: Mejor IA para video y YouTube · Fuente

15 de octubre

Meta Muse Spark Open

Modelo open-weight de Meta para código y agentes (816B parámetros, 42B activos, contexto de 1M de tokens). Meta lo corre en dos Mac Studio; para la mayoría, las APIs alojadas son la vía práctica.

Caso de uso: Mejores herramientas para ejecutar IA en local · Fuente

7 de octubre

Claude Haiku 5.5

El modelo más barato y rápido de Anthropic, pensado para trabajo de alto volumen como bots de soporte, resúmenes y subagentes de código. Según Anthropic, cuesta cerca de un 75% menos que Haiku 4.5.

Caso de uso: Mejor IA para chatbots y RAG · Fuente

6 de octubre

Nano Banana 2.1 (Google)

Modelo actualizado de generación y edición de imágenes de Google, con mejores ediciones, consistencia de personajes y texto en las imágenes. En la app de Gemini, AI Studio, la Gemini API, Flow y Stitch.

Caso de uso: Mejor IA para generar imágenes · Fuente

1 de octubre

GitHub Copilot dynamic workflows

Define en código trabajos con varios agentes (pasos en paralelo, subagentes que revisan a otros, checkpoints para que revises) en Copilot CLI, la app de Copilot y el Copilot SDK. Public preview, en todos los planes.

Caso de uso: Mejores agentes de IA para programar · Fuente

30 de septiembre

HeyGen Video

El primer modelo de video de uso general de HeyGen: clips de 5 a 15 segundos con diálogo y sonido generados juntos, a partir de texto, una imagen o material de referencia. Disponible por la API de HeyGen.

Caso de uso: Mejor IA para video y YouTube · Fuente

29 de septiembre

GPT-6.1 Sol

La mejora de GPT-6 Sol presentada en el DevDay de OpenAI, enfocada en programación con agentes, computer use y trabajo profesional. OpenAI dice que se acerca a GPT-6 Astra a un precio mucho menor.

Caso de uso: Mejores agentes de IA para programar · Fuente

29 de septiembre

OpenAI Agents API: computer use

La Agents API ahora maneja software con computer use y trae a tu app las funciones multiagente de Codex, tool search y compactación de contexto. OpenAI se encarga de la infraestructura.

Caso de uso: Mejores frameworks de agentes de IA · Fuente

28 de septiembre

Claude Sonnet 5.5

El Sonnet más rápido y barato de Anthropic, fuerte en tareas cotidianas bien acotadas y en corregir bugs. Más de un 30% más rápido que Sonnet 5, al mismo precio de US$2/US$10 por millón de tokens.

Caso de uso: Mejor IA para arreglar código roto y errores · Fuente

24 de septiembre

Lovable: free chat

Chatear con Lovable ahora es gratis dentro de un cupo diario: planifica funciones, pregunta por el código y la base de datos de tu app o redacta textos de lanzamiento. Construir sigue usando créditos.

Caso de uso: Mejor IA para vibe coding · Fuente

10 de septiembre

Cursor Projects

Beta para trabajos grandes, como una función o una migración: un agente coordinador corre en la nube, planifica el trabajo, lo reparte entre muchos subagentes y mantiene un contexto compartido con el tiempo.

Caso de uso: Mejores agentes de IA para programar · Fuente

Anteriores

Lanzamientos que destacamos antes de esta actualización. Ya no son novedad, pero vale la pena conocerlos.

  • Claude Code — El agente de programación de Anthropic para la terminal: una de las herramientas de desarrollo de las que más se habla.
  • OpenAI Codex — El agente de programación Codex, relanzado por OpenAI (nube + CLI).
  • Google Veo — El modelo de video de Google, que ahora genera audio sincronizado.
  • Manus — Agente autónomo de uso general que se hizo viral con sus tareas de varios pasos.
  • Lovable — Creador de apps a partir de prompts que está creciendo rápido.
  • Gemini Notebook (formerly NotebookLM) — Los resúmenes en audio (Audio Overviews) convirtieron notas de investigación en podcasts.
  • Kling — Un competidor fuerte en generación de video con IA.
  • DeepSeek — Modelos de razonamiento de pesos abiertos que sacudieron los precios del mercado.
  • Model Context Protocol — El protocolo abierto que ya admiten la mayoría de las herramientas de agentes para acceder a herramientas.
  • Devin Desktop (formerly Windsurf) — Editor agéntico que compite directamente con Cursor.
