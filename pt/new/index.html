Lançamentos e tendências

Lançamentos e grandes atualizações de ferramentas de IA das últimas seis semanas que importam para quem constrói. Cada um tem data, link para o anúncio oficial e o caso de uso em que se encaixa.

Atualizado em 26 de outubro de 2026

23 de outubro

Replit Monitoring Agent

O Agent do Replit agora acompanha os alertas de um app publicado em segundo plano, investiga problemas em produção e testa uma correção. Você revisa e publica a correção, a menos que ative a opção experimental Auto-republish.

Caso de uso: Melhor IA para corrigir código quebrado e erros · Fonte

20 de outubro

Lovable: creates your Supabase project

O Lovable agora cria um projeto Supabase para um app sem backend e já o conecta. Você escolhe a organização e a região (a região não pode ser alterada depois), e o Supabase cobra o projeto na sua própria conta.

Caso de uso: Melhor IA para vibe coding · Fonte

20 de outubro

Mistral Voxtral 3

Novos modelos de speech-to-text e text-to-speech da Mistral, mais um SDK para agentes de voz em tempo real por telefone e na web. Pela API da Mistral (com opção hospedada na UE) ou self-hosted.

Caso de uso: Melhor IA de voz e texto para fala · Fonte

15 de outubro

Kling 4.0

Novo modelo de vídeo da Kuaishou: clipes de até 30 segundos de uma vez, movimentos rápidos e de câmera mais estáveis e até 15 referências e 10 keyframes por tarefa.

Caso de uso: Melhor IA para vídeo e YouTube · Fonte

15 de outubro

Meta Muse Spark Open

Modelo open-weight da Meta para código e agentes (816B de parâmetros, 42B ativos, contexto de 1M de tokens). A Meta roda em dois Mac Studios; para a maioria, APIs hospedadas são o caminho prático.

Caso de uso: Melhores ferramentas para rodar IA localmente · Fonte

7 de outubro

Claude Haiku 5.5

O modelo mais barato e rápido da Anthropic, feito para trabalho em alto volume como bots de suporte, resumos e subagentes de código. Segundo a Anthropic, custa cerca de 75% menos que o Haiku 4.5.

Caso de uso: Melhor IA para chatbots e RAG · Fonte

6 de outubro

Nano Banana 2.1 (Google)

Modelo atualizado de geração e edição de imagens do Google, com edições melhores, mais consistência de personagens e texto nas imagens. No app Gemini, AI Studio, Gemini API, Flow e Stitch.

Caso de uso: Melhor IA para gerar imagens · Fonte

1 de outubro

GitHub Copilot dynamic workflows

Defina em código tarefas com vários agentes (etapas em paralelo, subagentes conferindo uns aos outros, checkpoints para você revisar) no Copilot CLI, no app do Copilot e no Copilot SDK. Public preview, em todos os planos.

Caso de uso: Melhores agentes de IA para programação · Fonte

30 de setembro

HeyGen Video

Primeiro modelo de vídeo de uso geral da HeyGen: clipes de 5 a 15 segundos com falas e som gerados juntos, a partir de texto, imagem ou mídia de referência. Disponível pela API da HeyGen.

Caso de uso: Melhor IA para vídeo e YouTube · Fonte

29 de setembro

GPT-6.1 Sol

Upgrade do GPT-6 Sol anunciado no DevDay da OpenAI, focado em código com agentes, computer use e trabalho profissional. A OpenAI diz que chega perto do GPT-6 Astra por um preço bem menor.

Caso de uso: Melhores agentes de IA para programação · Fonte

29 de setembro

OpenAI Agents API: computer use

A Agents API agora opera softwares via computer use e traz para o seu app os recursos multiagente do Codex, tool search e compactação de contexto. A OpenAI cuida da infraestrutura.

Caso de uso: Melhores frameworks de agentes de IA · Fonte

28 de setembro

Claude Sonnet 5.5

O Sonnet mais rápido e mais barato da Anthropic, melhor em tarefas do dia a dia bem definidas e correção de bugs. Mais de 30% mais rápido que o Sonnet 5, pelo mesmo preço de US$ 2/US$ 10 por milhão de tokens.

Caso de uso: Melhor IA para corrigir código quebrado e erros · Fonte

24 de setembro

Lovable: free chat

Conversar com o Lovable agora é grátis dentro de uma cota diária: planeje features, pergunte sobre o código e o banco de dados do app ou rascunhe textos de lançamento. Construir ainda consome créditos.

Caso de uso: Melhor IA para vibe coding · Fonte

10 de setembro

Cursor Projects

Beta para trabalhos grandes, como uma feature ou uma migração: um agente coordenador roda na nuvem, planeja o trabalho, distribui para muitos subagentes e mantém um contexto compartilhado ao longo do tempo.

Caso de uso: Melhores agentes de IA para programação · Fonte

Anteriores

Lançamentos que destacamos antes desta atualização. Não são mais novidade, mas ainda vale conhecer.

  • Claude Code — O agente de código da Anthropic que roda no terminal — uma das ferramentas de dev mais comentadas.
  • OpenAI Codex — O agente de código Codex, relançado pela OpenAI (nuvem + CLI).
  • Google Veo — O modelo de vídeo do Google, que agora gera áudio sincronizado.
  • Manus — Agente autônomo de uso geral que viralizou com tarefas de várias etapas.
  • Lovable — Construtor de apps a partir de prompts que está crescendo rápido.
  • Gemini Notebook (formerly NotebookLM) — Os resumos em áudio (Audio Overviews) transformaram notas de pesquisa em podcasts.
  • Kling — Concorrente forte em geração de vídeo com IA.
  • DeepSeek — Modelos de raciocínio com pesos abertos que mexeram com os preços do mercado.
  • Model Context Protocol — O protocolo aberto que a maioria das ferramentas de agentes já suporta para acesso a ferramentas.
  • Devin Desktop (formerly Windsurf) — Editor agêntico que concorre diretamente com o Cursor.
