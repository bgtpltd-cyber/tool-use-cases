Melhor IA para criar extensões do Chrome

Do 'devia ter um botão pra isso' a uma extensão de navegador funcionando.

Patrocinado

Sua ferramenta aqui

Este espaço em destaque está disponível para criadores de ferramentas que se encaixam neste caso de uso. Sempre identificado com clareza e sempre separado das nossas escolhas.

Patrocinar por e-mail

Nossas escolhas

  1. 1. Cursor

    Editor de código pensado para IA (um fork do VS Code), com chat, edição inline e modo agente.

    Veredito: Escolha nº 1: gera o manifest, os scripts e o popup, e corrige erros no contexto enquanto você recarrega e testa.

  2. 2. Claude Code

    Ferramenta de programação agêntica da Anthropic que roda no terminal.

    Veredito: Ótimo para montar a estrutura da extensão inteira e iterar nos problemas de permissão do Manifest V3.

  3. 3. ChatGPT

    Assistente de IA de uso geral da OpenAI, com chat, imagens, voz e busca.

    Veredito: Serve para uma extensão pequena, de um arquivo só. Confira se ele usa o Manifest V3, porque exemplos antigos estão por toda parte.

  4. 4. Plasmo

    Framework open source para criar extensões de navegador com React e TypeScript.

    Veredito: Não é uma ferramenta de IA, mas combina bem com uma: framework React/TS que elimina o boilerplate de extensões.

  5. 5. GitHub Copilot

    Assistente de programação em par com IA, integrado ao VS Code, às IDEs da JetBrains e ao GitHub.

    Veredito: Bom autocomplete para as APIs do Chrome se você prefere escrever o código você mesmo.

As escolhas são editoriais e não são pagas. Preços e recursos mudam com frequência — confira o site oficial de cada ferramenta.
