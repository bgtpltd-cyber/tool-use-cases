UI design-এর সেরা AI

Prompt বা sketch থেকে screens, তারপর এমন কিছু যা আপনি বানাতে পারবেন।

Sponsored

আপনার টুল এখানে

এই ফিচার্ড স্লটটা সেইসব টুল নির্মাতাদের জন্য, যাদের টুল এই use case-এ সত্যিই মানানসই। সবসময় পরিষ্কারভাবে লেবেল করা থাকে এবং আমাদের বাছাই থেকে আলাদা রাখা হয়।

স্পনসর করতে ইমেল করুন

আমাদের বাছাই

  1. 1. Figma

    UI ডিজাইনের standard টুল, বিল্ট-ইন AI ফিচার আর prompt-to-prototype-এর জন্য Figma Make সহ।

    আমাদের মত: টপ পিক, যদি ডিজাইনারদের সঙ্গে কাজ করেন: standard টুল, এখন AI আর Figma Make বিল্ট-ইন সহ।

  2. 2. v0

    Vercel-এর AI app/UI builder, যা prompts থেকে React + Tailwind অ্যাপ বানায়।

    আমাদের মত: Mockup-এর ধাপটাই বাদ দেয়: চালু UI কোড বানায়, যা সঙ্গে সঙ্গে ship করা যায়।

  3. 3. Google Stitch

    Google-এর prompt-to-UI ডিজাইন টুল (আগে Galileo AI), যা Figma আর কোডে export করে।

    আমাদের মত: Google-এর ফ্রি আর দ্রুত prompt-to-UI exploration (আগে Galileo AI); Figma-তে export করে।

  4. 4. Uizard

    নতুনদের জন্য সহজ AI UI mockup টুল; prompts আর sketches-কে অ্যাপ স্ক্রিনে বদলায়।

    আমাদের মত: Wireframes বানানো non-designers-দের জন্য সবচেয়ে সহজ; pixel-level কন্ট্রোল চাইলে বাদ দিন।

  5. 5. Lovable

    Prompt থেকে full-stack ওয়েব অ্যাপ বানানোর builder, Supabase integration সহ।

    আমাদের মত: যখন 'ডিজাইন'-টা আসলে একটা clickable, চালু অ্যাপ হতে হবে।

এই বাছাই আমাদের নিজেদের, এর জন্য কেউ টাকা দেয়নি। দাম আর ফিচার প্রায়ই বদলায় — প্রতিটা টুলের অফিশিয়াল সাইট দেখে নিন।
