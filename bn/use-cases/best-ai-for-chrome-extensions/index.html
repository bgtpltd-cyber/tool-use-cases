Chrome extensions বানানোর সেরা AI

'এটার জন্য একটা বোতাম থাকা উচিত' থেকে চালু browser extension পর্যন্ত।

Sponsored

আপনার টুল এখানে

এই ফিচার্ড স্লটটা সেইসব টুল নির্মাতাদের জন্য, যাদের টুল এই use case-এ সত্যিই মানানসই। সবসময় পরিষ্কারভাবে লেবেল করা থাকে এবং আমাদের বাছাই থেকে আলাদা রাখা হয়।

স্পনসর করতে ইমেল করুন

আমাদের বাছাই

  1. 1. Cursor

    AI-first কোড এডিটর (VS Code-এর fork), যাতে chat, inline edits আর agent mode আছে।

    আমাদের মত: টপ পিক: manifest, scripts আর popup বানায়, আর আপনি reload করে টেস্ট করার সময় context ধরে errors ঠিক করে।

  2. 2. Claude Code

    Anthropic-এর terminal-এ চলা agentic coding টুল।

    আমাদের মত: পুরো extension-এর কাঠামো দাঁড় করাতে আর Manifest V3 permission issues নিয়ে বারবার কাজ করতে দারুণ।

  3. 3. ChatGPT

    OpenAI-এর সব কাজের AI অ্যাসিস্ট্যান্ট, chat, images, voice আর search সহ।

    আমাদের মত: ছোট, এক ফাইলের extension-এর জন্য ঠিক আছে। দেখে নিন Manifest V3 ব্যবহার করছে কিনা, কারণ পুরনো examples সব জায়গায় ছড়িয়ে আছে।

  4. 4. Plasmo

    React আর TypeScript দিয়ে browser extensions বানানোর open-source framework।

    আমাদের মত: নিজে AI টুল নয়, কিন্তু AI টুলের সঙ্গে ভালো চলে: React/TS framework, যা extension-এর boilerplate সরিয়ে দেয়।

  5. 5. GitHub Copilot

    AI pair programmer, VS Code, JetBrains আর GitHub-এ বিল্ট-ইন।

    আমাদের মত: নিজে লিখতে চাইলে Chrome APIs-এর জন্য ভালো autocomplete।

এই বাছাই আমাদের নিজেদের, এর জন্য কেউ টাকা দেয়নি। দাম আর ফিচার প্রায়ই বদলায় — প্রতিটা টুলের অফিশিয়াল সাইট দেখে নিন।
