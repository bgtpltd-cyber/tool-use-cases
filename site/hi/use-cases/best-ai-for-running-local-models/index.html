AI को लोकली चलाने के लिए बेस्ट टूल्स

आपकी अपनी मशीन पर प्राइवेट AI, जिसे चलाने का कोई खर्च नहीं।

Sponsored

आपका टूल यहाँ

यह फ़ीचर्ड स्लॉट उन टूल बनाने वालों के लिए है जिनका टूल इस use case में सच में फ़िट बैठता है। हमेशा साफ़ तौर पर लेबल किया जाता है और हमारी पसंद से हमेशा अलग रहता है।

स्पॉन्सर करने के लिए ईमेल करें

हमारी पसंद

  1. 1. Ollama

    Open models (Llama, Qwen वगैरह) को एक command से लोकली चलाएँ।

    हमारी राय: एक command से open models डाउनलोड करें और चलाएँ; शुरुआत का सबसे आसान तरीका।

  2. 2. DeepSeek

    चीन की AI लैब, जिसके open-weight reasoning models दमदार और सस्ते हैं।

    हमारी राय: दमदार open-weight models, जिन्हें लोकली चला सकते हैं या API से सस्ते में इस्तेमाल कर सकते हैं।

  3. 3. Aider

    Terminal में open-source AI pair programming, जो git को समझता है।

    हमारी राय: इसे किसी local model के साथ जोड़ें और offline coding असिस्टेंट पाएँ।

  4. 4. Stable Diffusion

    Open image models की फ़ैमिली, जिसे आप लोकली चला सकते हैं (जैसे ComfyUI से)।

    हमारी राय: Local image models का क्लासिक ecosystem।

ये पसंद हमारी अपनी है, इसके लिए किसी ने पैसे नहीं दिए। कीमतें और फ़ीचर्स अक्सर बदलते रहते हैं — हर टूल की ऑफ़िशियल साइट ज़रूर चेक करें।
