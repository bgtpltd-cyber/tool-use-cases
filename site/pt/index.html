Qual ferramenta de IA para cada tarefa.

O Tool Use Cases é um diretório de ferramentas de IA organizadas pela tarefa que você quer resolver — para vibe coders, builders e qualquer pessoa que coloca projetos no ar com IA.

Casos de uso

Melhor IA para vibe coding

Descreva, rode, ajuste. Ferramentas para criar software basicamente conversando.

Cursor, Lovable, v0, Replit Agent, Bolt.new, Windsurf

Melhores agentes de IA para programação

Agentes que pegam uma tarefa, editam vários arquivos, rodam comandos e voltam com um diff.

Claude Code, Cursor, OpenAI Codex, GitHub Copilot, Devin, Aider

Melhor IA para corrigir código quebrado e erros

Cole o stack trace e receba a correção. Ferramentas boas em debugar, não só em gerar código.

Claude, Cursor, ChatGPT, GitHub Copilot, Sentry (Seer), Claude Code

Melhor IA para prototipar jogos

Coloque uma ideia jogável na tela rápido — código, arte, 3D e música.

Rosebud AI, Cursor, Scenario, Meshy, Suno, ElevenLabs

Melhor IA para vídeo e YouTube

Gere cenas, edite mais rápido, coloque voz e corte tudo em Shorts.

Descript, Runway, Google Veo, ElevenLabs, OpusClip, CapCut, HeyGen

Melhores assistentes de escrita com IA

Rascunhar, editar e reescrever — documentos, posts de blog, READMEs, e-mails.

Claude, ChatGPT, Notion AI, Grammarly, Gemini

Melhor IA para pesquisa

Encontre fontes, leia e resuma — com citações que você pode conferir.

Perplexity, NotebookLM, ChatGPT, Gemini, Elicit, Grok

Melhor IA para gerar imagens

Thumbnails, arte conceitual, mockups, memes.

Midjourney, ChatGPT Images, Ideogram, FLUX (Black Forest Labs), Adobe Firefly, Stable Diffusion

Melhores ferramentas para rodar IA localmente

IA privada e sem custo de uso, na sua própria máquina.

Ollama, DeepSeek, Aider, Stable Diffusion

Melhor IA para fluxos de automação

Conecte seus apps e deixe a IA cuidar das etapas repetitivas — triggers, agentes e código de integração.

n8n, Make, Zapier, Claude Code, Manus

Melhor IA para landing pages

Da ideia a uma landing page no ar e com cara decente em uma tarde.

Lovable, Framer, v0, Bolt.new, Cursor

Melhor IA para design de UI

Transforme um prompt ou esboço em telas e, depois, em algo que dá para construir.

Figma, v0, Google Stitch, Uizard, Lovable

Melhor IA de voz e texto para fala

Locuções, narração, vozes clonadas e fala para apps, sem microfone.

ElevenLabs, OpenAI Text-to-Speech, Descript, HeyGen

Melhor IA para música

Músicas, trilhas sonoras e música de fundo a partir de um prompt.

Suno, Udio, AIVA, ElevenLabs

Melhor IA para conteúdo de SEO

Pesquise, estruture e escreva páginas que podem ranquear — sem publicar lixo gerado por IA.

Claude, Surfer, Clearscope, Perplexity, ChatGPT

Melhor IA para e-mails de vendas

Escreva cold e-mails e follow-ups melhores — pessoais, curtos e sem cara de IA.

Claude, ChatGPT, Lavender, Perplexity, Grammarly

Melhor IA para dados e planilhas

Analise CSVs, escreva fórmulas e crie gráficos pedindo em linguagem natural.

ChatGPT, Claude, Julius AI, Microsoft 365 Copilot (Excel), Gemini

Melhor IA para apresentações

Do roteiro a uma apresentação decente, em pouco tempo.

Gamma, Beautiful.ai, Claude, ChatGPT, Microsoft 365 Copilot (PowerPoint)

Melhor IA para assets 3D

Gere props, personagens e modelos a partir de texto ou imagens.

Meshy, Tripo, Luma AI, Scenario, Stable Diffusion

Melhor IA para notas de reunião

Grave, transcreva e resuma reuniões para ninguém precisar fazer anotações.

Fireflies.ai, Otter.ai, Grain, Notion AI, Claude

Melhor IA para chatbots e RAG

Crie um assistente que responde com base nos seus próprios documentos — do no-code ao código sob medida.

ChatGPT, Claude, LlamaIndex, LangChain, Cursor, NotebookLM

Melhor hospedagem para apps feitos com IA

Onde colocar no ar o app que suas ferramentas de IA acabaram de criar. Estas são plataformas de hospedagem, não ferramentas de IA — escolhidas pelo quanto combinam com quem constrói com ajuda de IA.

Vercel, Netlify, Railway, Fly.io, Replit Agent

Melhor IA para criar extensões do Chrome

Do 'devia ter um botão pra isso' a uma extensão de navegador funcionando.

Cursor, Claude Code, ChatGPT, Plasmo, GitHub Copilot

Melhor IA para thumbnails e títulos no YouTube

Thumbnails, títulos e o gancho que faz a pessoa clicar.

Ideogram, ChatGPT Images, Canva, Midjourney, Claude

Melhores frameworks de agentes de IA

Frameworks em código para criar seus próprios agentes com ferramentas, memória e workflows de várias etapas.

OpenAI Agents SDK, LangGraph, CrewAI, AutoGen, Model Context Protocol

Melhor IA para logos e branding

Ideias de logo, símbolos de marca e um brand kit inicial, em pouco tempo.

Recraft, Ideogram, Looka, Midjourney, ChatGPT Images

Melhor IA para atendimento ao cliente

Responda os clientes mais rápido com agentes de IA e respostas rascunhadas por IA.

Intercom Fin, Zendesk AI, Help Scout, Claude, ChatGPT

Melhor IA para web scraping

Firecrawl, Apify, Browserbase, Claude Code, Cursor

Lançamentos e tendências

  • Claude Code — O agente de código da Anthropic que roda no terminal — uma das ferramentas de dev mais comentadas.
  • OpenAI Codex — O agente de código Codex, relançado pela OpenAI (nuvem + CLI).
  • Google Veo — O modelo de vídeo do Google, que agora gera áudio sincronizado.
  • Sora — O modelo de vídeo da OpenAI, agora com seu próprio app social.
  • Manus — Agente autônomo de uso geral que viralizou com tarefas de várias etapas.
