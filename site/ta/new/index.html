புதிய launches, trending

கடந்த ஆறு வாரங்களில் வந்த, builders-க்கு முக்கியமான AI tool launches மற்றும் பெரிய updates. ஒவ்வொன்றுக்கும் தேதி, அதிகாரப்பூர்வ அறிவிப்பின் link, அது பொருந்தும் use case ஆகியவற்றைக் கொடுத்துள்ளோம்.

கடைசியாக update செய்தது: அக்டோபர் 22, 2026

அக்டோபர் 20

Mistral Voxtral 3

Mistral-இன் புதிய speech-to-text, text-to-speech models, கூடவே phone, web-இல் real-time voice agents உருவாக்க ஒரு SDK. Mistral API (EU-hosted option உடன்) வழியாக அல்லது self-hosted.

Use case: சிறந்த AI voice, text-to-speech · ஆதாரம்

அக்டோபர் 15

Kling 4.0

Kuaishou-வின் புதிய video model: ஒரே pass-இல் 30 வினாடிகள் வரை clips, வேகமான அசைவுகள், camera moves-இல் அதிக நிலைத்தன்மை, ஒவ்வொரு வேலைக்கும் 15 வரை reference assets, 10 keyframes.

Use case: Video, YouTube-க்கு சிறந்த AI · ஆதாரம்

அக்டோபர் 15

Meta Muse Spark Open

Coding, agent வேலைகளுக்கான Meta-வின் open-weight model (816B parameters, 42B active, 1M-token context). Meta இதை இரண்டு Mac Studios-இல் இயக்குகிறது; பெரும்பாலானோருக்கு hosted APIs-தான் எளிய வழி.

Use case: AI-ஐ local-ஆக run செய்ய சிறந்த tools · ஆதாரம்

அக்டோபர் 7

Claude Haiku 5.5

Anthropic-இன் மிக மலிவான, மிக வேகமான model; support bots, summaries, coding subagents போன்ற அதிக அளவு வேலைகளுக்கானது. Haiku 4.5-ஐ விட இயக்க சுமார் 75% குறைவான செலவு என்கிறது Anthropic.

Use case: Chatbots, RAG-க்கு சிறந்த AI · ஆதாரம்

அக்டோபர் 6

Nano Banana 2.1 (Google)

Google-இன் update செய்யப்பட்ட image generation, editing model: சிறந்த edits, கதாபாத்திரங்களில் அதிக consistency, images-இல் தெளிவான text. Gemini app, AI Studio, Gemini API, Flow, Stitch-இல் கிடைக்கிறது.

Use case: Image generation-க்கு சிறந்த AI · ஆதாரம்

அக்டோபர் 1

GitHub Copilot dynamic workflows

Multi-agent வேலைகளை code-இல் வரையறுக்கலாம் (parallel steps, ஒன்றையொன்று சரிபார்க்கும் subagents, நீங்கள் review செய்ய checkpoints) — Copilot CLI, Copilot app, Copilot SDK-இல். Public preview, எல்லா plans-இலும்.

Use case: சிறந்த AI coding agents · ஆதாரம்

செப்டம்பர் 30

HeyGen Video

HeyGen-இன் முதல் general-purpose video model: text, image அல்லது reference media-விலிருந்து 5 முதல் 15 வினாடி clips; வசனமும் ஒலியும் சேர்ந்தே உருவாகின்றன. HeyGen API வழியாகக் கிடைக்கிறது.

Use case: Video, YouTube-க்கு சிறந்த AI · ஆதாரம்

செப்டம்பர் 29

GPT-6.1 Sol

OpenAI DevDay-இல் வந்த GPT-6 Sol upgrade; agentic coding, computer use, professional வேலைகளில் கவனம். மிகக் குறைந்த விலையில் GPT-6 Astra-வுக்கு நெருக்கமாக வருகிறது என்கிறது OpenAI.

Use case: சிறந்த AI coding agents · ஆதாரம்

செப்டம்பர் 29

OpenAI Agents API: computer use

Agents API இப்போது computer use மூலம் software-ஐ இயக்க முடியும்; Codex-இன் multi-agent features, tool search, context compaction-ஐ உங்கள் app-க்குக் கொண்டு வருகிறது. Infrastructure-ஐ OpenAI இயக்குகிறது.

Use case: சிறந்த AI agent frameworks · ஆதாரம்

செப்டம்பர் 28

Claude Sonnet 5.5

Anthropic-இன் வேகமான, மலிவான Sonnet; தெளிவான எல்லை கொண்ட அன்றாட வேலைகள், bug fixing-இல் வலிமையானது. Sonnet 5-ஐ விட 30%+ வேகம், அதே $2/$10 per million tokens விலையில்.

Use case: உடைந்த code, errors-ஐ சரிசெய்ய சிறந்த AI · ஆதாரம்

செப்டம்பர் 24

Lovable: free chat

Lovable உடன் chat இப்போது தினசரி free அளவுக்குள் இலவசம்: features-ஐ plan செய்யலாம், app-இன் code, database பற்றிக் கேட்கலாம், launch text-ஐ draft செய்யலாம். Build செய்ய இன்னும் credits தேவை.

Use case: Vibe coding-க்கு சிறந்த AI · ஆதாரம்

செப்டம்பர் 10

Cursor Projects

ஒரு feature அல்லது migration போன்ற பெரிய வேலைகளுக்கான beta: ஒரு coordinator agent cloud-இல் இயங்கி, வேலையை plan செய்து, பல subagents-க்குப் பிரித்துக் கொடுத்து, காலப்போக்கில் shared context-ஐப் பராமரிக்கிறது.

Use case: சிறந்த AI coding agents · ஆதாரம்

முந்தையவை

இந்த update-க்கு முன் நாங்கள் காட்டிய launches. இப்போது இவை புதியவை அல்ல, ஆனால் தெரிந்துகொள்ள வேண்டியவை.

  • Claude Code — Anthropic-இன் terminal coding agent — அதிகம் பேசப்படும் dev tools-இல் ஒன்று.
  • OpenAI Codex — OpenAI மீண்டும் launch செய்த Codex coding agent (cloud + CLI).
  • Google Veo — Google-இன் video model, இப்போது synced audio-வும் உருவாக்கும்.
  • Manus — Multi-step tasks-ஆல் viral ஆன autonomous general agent.
  • Lovable — வேகமாக வளரும் prompt-to-app builder.
  • Gemini Notebook (formerly NotebookLM) — Audio Overviews, research notes-ஐ podcasts-ஆக மாற்றியது.
  • Kling — AI video generation-இல் வலுவான போட்டியாளர்.
  • DeepSeek — Pricing-ஐயே அசைத்துப் பார்த்த open-weight reasoning models.
  • Model Context Protocol — இப்போது பெரும்பாலான agent tools, tools access-க்கு support செய்யும் open protocol.
  • Devin Desktop (formerly Windsurf) — Cursor-உடன் நேரடியாகப் போட்டியிடும் agentic editor.

Vibe coders-க்கு ஒவ்வொரு வாரமும் தேர்ந்தெடுத்த AI tools
