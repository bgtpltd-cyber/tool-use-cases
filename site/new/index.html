Friday, Nov 13, 2026 Permalink

  • Breaking changeCodex: In rust-v0.169.0 (Nov 13, 2026), codex exec keeps project configuration and MCP servers disabled in untrusted directories, even with --sandbox workspace-write.

    Test for this: If CI runs codex exec in a fresh checkout and relies on project config or MCP servers, run it after upgrading and check they load. The release notes say to use --trust with codex exec or codex review to explicitly save project trust.

    Source: openai/codex release rust-v0.169.0 · Checked 10:18 AM PT · Fits: Best AI coding agents

  • Breaking changeOpenCode: In v2.3.0 (Nov 13, 2026), subagents run in the background by default: they return immediately and report back when idle. Transcript verbosity also now defaults to low.

    Test for this: If a workflow expects a subagent's result before the next step, run it after upgrading and check the order still holds. To see every tool step again, set session.verbosity to medium or high; an existing setting is kept.

    Source: anomalyco/opencode release v2.3.0 · Checked 10:18 AM PT · Fits: Best AI coding agents

  • Breaking changeClaude Code: In v2.1.323 (Nov 12, 2026), plugin.json accepts engines["claude-code"]: plugins outside their stated Claude Code version range are not installed, updated or loaded.

    Test for this: If you publish a plugin, set an engines["claude-code"] range you have tested and run claude plugin validate; if you install plugins, check after upgrading that the ones you rely on still load.

    Source: anthropics/claude-code release v2.1.323 · Checked 10:18 AM PT · Fits: Best AI coding agents

Thursday, Nov 12, 2026 Permalink

  • Breaking changeCodex: In rust-v0.167.2 (Nov 11, 2026), Codex now sends tool updates incrementally by default on Google Cloud Vertex AI.

    Test for this: If you run Codex on Vertex AI, run a tool-heavy task after upgrading and check tool calls still complete. The release notes give the opt-out: set incremental_tools_legacy_gcp = false under [features] in config.toml.

    Source: openai/codex release rust-v0.167.2 · Checked 10:20 AM PT · Fits: Best AI coding agents

  • Breaking changeLangGraph CLI: In langgraph-cli 0.4.43 (Nov 12, 2026), the discontinued local debugger image is removed: langgraph up --debugger-port now returns "No such option". New --studio-url and --api-url flags point to hosted Studio.

    Test for this: Search your scripts, Makefiles and CI for --debugger-port and remove it before upgrading; use the printed Studio link, or --studio-url and --api-url, instead.

    Source: langchain-ai/langgraph PR #8543 (shipped in cli==0.4.43) · Checked 10:22 AM PT · Fits: Best AI agent frameworks

  • Breaking changeCrewAI: In crewAI 1.15.40 (Nov 11, 2026), openai, azure and openrouter embedders use a native OpenAI function: no CHROMA_OPENAI_API_KEY fallback, and empty input raises ValueError instead of returning [].

    Test for this: If your embedder key lives only in CHROMA_OPENAI_API_KEY, move it to api_key, EMBEDDINGS_OPENAI_API_KEY or OPENAI_API_KEY, then run Knowledge or RAG with an empty document to see how your code handles the new ValueError.

    Source: crewAIInc/crewAI PR #8934 (shipped in 1.15.40) · Checked 10:23 AM PT · Fits: Best AI agent frameworks

Wednesday, Nov 11, 2026 Permalink

  • Breaking changeMCP servers (server-filesystem): v2.4.0 (Nov 11, 2026) fixes two vulnerabilities in @modelcontextprotocol/server-filesystem 2.3.0. Package managers rank 2.3.0 below every 2025.x and 2026.x date version, so they won't offer it as an upgrade.

    Test for this: If you run a date version of server-filesystem, install it explicitly: npm install @modelcontextprotocol/server-filesystem@2.3.0, then confirm the version your MCP client launches.

    Source: modelcontextprotocol/servers release v2.4.0 · Checked 10:17 AM PT · Fits: Best AI agent frameworks

  • Breaking changeMCP servers (mcp-server-git): mcp-server-git 2026.11.11 (in v2.4.0) stops a repository's own Git config from making the server run a program, and refuses a Git older than 2.31.

    Test for this: Run git --version on every machine or image that runs mcp-server-git; upgrade Git to 2.31 or newer before moving to 2026.11.11.

    Source: modelcontextprotocol/servers release v2.4.0 · Checked 10:17 AM PT · Fits: Best AI agent frameworks

  • Breaking changeMCP servers (mcp-server-fetch): mcp-server-fetch 2026.11.11 (in v2.4.0) now refuses IPv6 site-local fec0::/10 and other IPv6 addresses outside 2000::/3 without an IPv4 address, and matches robots.txt against the resolved path.

    Test for this: After upgrading, re-run any fetch calls that hit internal IPv6 hosts or paths like //private; expect them to be refused now.

    Source: modelcontextprotocol/servers release v2.4.0 · Checked 10:17 AM PT · Fits: Best AI agent frameworks

    Source: Claude Code release v2.1.319 · Checked 10:08 AM PT · Fits: Best AI coding agents

GitHub Copilot in Xcode's coding assistant (public preview)

Use GitHub Copilot directly in Xcode's built-in coding assistant, starting with Xcode 27.3 beta on macOS Tahoe 26.6 or later. Set it up under Xcode > Settings > Intelligence. All Copilot plans are supported, and the separate Copilot for Xcode extension stays available.

MCP reference servers v2.3.0

The official Model Context Protocol reference servers got a new release. The filesystem server adds append_file, copy_file, a --read-only mode and --confine-roots; fetch adds a --allowed-hosts allowlist and a configurable timeout; git adds git_merge and git_remote; time adds get_time_ago.
