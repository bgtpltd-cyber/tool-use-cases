ユースケース /

おすすめのAI agent framework

ツール、メモリ、複数ステップのワークフローを持つ自分だけのagentを作るための、コード向けframework。

スポンサー

あなたのツールをここに

この注目枠は、このユースケースに本当に合うツールを作っている方向けです。必ず明記し、編集部のおすすめとは常に分けて表示します。

メールでスポンサーを申し込む

おすすめ

  1. 1. OpenAI Agents SDK

    OpenAIの軽量なAgents SDK。ツール、handoff、guardrail、tracingに対応。

    ひとこと： 始めるなら一番のおすすめ。小さなAPIに、ツール、handoff、tracingが組み込まれています。

  2. 2. LangGraph

    LangChainの、状態を持ち制御しやすい複数ステップのagentグラフ用framework。

    ひとこと： 状態、リトライ、human-in-the-loop、本番での信頼性など、明示的な制御が必要なときに一番。

  3. 3. CrewAI

    ロールベースのAI agentチームを作るオープンソースのPython framework。

    ひとこと： ロールベースのマルチagent「crew」を最速でプロトタイプできます。規模が大きくなると制御しにくくなります。

  4. 4. Microsoft Agent Framework

    MicrosoftのPython・.NET向けオープンソースagent framework。AutoGenとSemantic Kernelの後継。

    ひとこと： MicrosoftによるAutoGenとSemantic Kernelの後継。Pythonでも.NETでもagentとグラフ型のワークフローを組めます。Azureを使うなら自然な選択。

  5. 5. Model Context Protocol

    AI agentをツールやデータにつなぐためのオープン標準。

    ひとこと： frameworkではありませんが、どのagentにもツールを渡せる標準的な方法。ツールはMCPサーバーとして作りましょう。

おすすめは編集部の判断で、掲載料は受け取っていません。料金や機能はよく変わるので、各ツールの公式サイトで確認してください。
