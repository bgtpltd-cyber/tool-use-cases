ユースケース /

UIデザインにおすすめのAI

promptやスケッチを画面に、そして実際に作れるものに。

スポンサー

あなたのツールをここに

この注目枠は、このユースケースに本当に合うツールを作っている方向けです。必ず明記し、編集部のおすすめとは常に分けて表示します。

メールでスポンサーを申し込む

おすすめ

  1. 1. Figma

    定番のUIデザインツール。AI機能と、promptからプロトタイプを作るFigma Makeを搭載。

    ひとこと： デザイナーと一緒に仕事をするなら一番のおすすめ。定番ツールに、AIとFigma Makeが組み込まれました。

  2. 2. v0

    VercelのAIアプリ/UIビルダー。promptからReact + Tailwindのアプリを生成。

    ひとこと： モックアップを飛ばして、そのまま公開できる動くUIコードを生成します。

  3. 3. Google Stitch

    GoogleのpromptからUIを作るデザインツール（旧Galileo AI）。Figmaやコードに書き出せる。

    ひとこと： Googleの無料で速い、promptからのUI探索ツール（旧Galileo AI）。Figmaに書き出せます。

  4. 4. Uizard

    初心者向けのAI UIモックアップツール。promptや手書きスケッチをアプリ画面に変換。

    ひとこと： デザイナーでない人がワイヤーフレームを作るなら一番簡単。ピクセル単位でこだわりたいなら避けましょう。

  5. 5. Lovable

    promptからフルスタックのWebアプリを作れるビルダー。Supabase連携あり。

    ひとこと： 「デザイン」が実際にはクリックして動くアプリである必要があるときに。

おすすめは編集部の判断で、掲載料は受け取っていません。料金や機能はよく変わるので、各ツールの公式サイトで確認してください。
