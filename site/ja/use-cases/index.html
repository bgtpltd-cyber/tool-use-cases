ユースケース

やりたいことを選んでください。試す価値のあるツールと、その理由を紹介します。

Vibe codingにおすすめのAI

説明して、動かして、調整する。ほぼ会話だけでソフトウェアを作れるツール。

Cursor, Lovable, v0, Replit Agent, Bolt.new, Devin Desktop (formerly Windsurf)

おすすめのAI coding agent

タスクを受け取り、複数のファイルを編集し、コマンドを実行してdiffを返してくれるagent。

Claude Code, Cursor, OpenAI Codex, GitHub Copilot, Devin, OpenCode

壊れたコードやエラーの修正におすすめのAI

stack traceを貼れば修正が返ってくる。コード生成だけでなく、debuggingに強いツール。

Claude, Cursor, ChatGPT, GitHub Copilot, Sentry (Seer), Claude Code

ゲームのプロトタイピングにおすすめのAI

遊べるアイデアを素早く画面に。コード、アート、3D、音楽まで。

Rosebud AI, Cursor, Scenario, Meshy, Suno, ElevenLabs

動画・YouTubeにおすすめのAI

映像を生成し、編集を速くし、声を入れて、Shortsに切り出す。

Descript, Runway, Google Veo, ElevenLabs, OpusClip, CapCut, HeyGen

おすすめのAIライティングアシスタント

下書き、編集、書き直し。ドキュメント、ブログ記事、README、メールに。

Claude, ChatGPT, Notion AI, Grammarly, Gemini

リサーチにおすすめのAI

ソースを見つけ、読み、要約する。確認できる引用つきで。

Perplexity, Gemini Notebook (formerly NotebookLM), ChatGPT, Gemini, Elicit, Grok

画像生成におすすめのAI

サムネイル、コンセプトアート、モックアップ、ミームに。

Midjourney, ChatGPT Images, Ideogram, FLUX (Black Forest Labs), Adobe Firefly, Stable Diffusion

AIをローカルで動かすためのおすすめツール

自分のマシンで、プライベートに、従量課金なしで使えるAI。

Ollama, DeepSeek, OpenCode, Stable Diffusion

自動化ワークフローにおすすめのAI

アプリ同士をつないで、繰り返しの作業はAIに任せる。トリガー、agent、つなぎのコードまで。

n8n, Make, Zapier, Claude Code, Manus

ランディングページ作りにおすすめのAI

アイデアから、公開できるきれいなランディングページまで午後のうちに。

Lovable, Framer, v0, Bolt.new, Cursor

UIデザインにおすすめのAI

promptやスケッチを画面に、そして実際に作れるものに。

Figma, v0, Google Stitch, Uizard, Lovable

音声・text-to-speechにおすすめのAI

マイクなしで、ナレーション、読み上げ、ボイスクローン、アプリの音声を。

ElevenLabs, OpenAI Text-to-Speech, Descript, HeyGen

音楽におすすめのAI

promptから、曲、サウンドトラック、BGMを。

Suno, Lyria in Gemini, AIVA, ElevenLabs

SEOコンテンツにおすすめのAI

AIの粗製コンテンツを公開せずに、上位表示を狙えるページを調べ、構成し、書く。

Claude, Surfer, Clearscope, Perplexity, ChatGPT

営業メールにおすすめのAI

パーソナルで短く、AIっぽさのないcold emailとフォローアップを書く。

Claude, ChatGPT, Lavender, Perplexity, Grammarly

データ・スプレッドシートにおすすめのAI

普通の言葉で頼むだけで、CSVを分析し、数式を書き、グラフを作る。

ChatGPT, Claude, Julius AI, Microsoft 365 Copilot (Excel), Gemini

プレゼン資料作りにおすすめのAI

アウトラインからちゃんとしたスライドまで、素早く。

Gamma, Beautiful.ai, Claude, ChatGPT, Microsoft 365 Copilot (PowerPoint)

3DアセットにおすすめのAI

テキストや画像から、小物、キャラクター、モデルを生成。

Meshy, Tripo, Hyper3D Rodin, Scenario, Stable Diffusion

議事録におすすめのAI

通話を録音・文字起こし・要約して、誰もメモを取らなくていいように。

Fireflies.ai, Otter.ai, Grain, Notion AI, Claude

チャットボット・RAGにおすすめのAI

自分のドキュメントをもとに答えるアシスタントを作る。ノーコードからカスタムコードまで。

Claude, ChatGPT, LlamaIndex, LangChain, Cursor, Gemini Notebook (formerly NotebookLM)

AIで作ったアプリにおすすめのホスティング

AIツールで作ったばかりのアプリをどこで公開するか。これらはAIツールではなくホスティング基盤で、AIを使って作る人との相性で選んでいます。

Vercel, Netlify, Railway, Fly.io, Replit Agent

Chrome拡張機能作りにおすすめのAI

「これ用のボタンがあればいいのに」から、動くブラウザ拡張機能へ。

Cursor, Claude Code, ChatGPT, WXT, GitHub Copilot

YouTubeのサムネイル・タイトルにおすすめのAI

クリックを生むサムネイル、タイトル、つかみ。

Ideogram, ChatGPT Images, Canva, Midjourney, Claude

おすすめのAI agent framework

ツール、メモリ、複数ステップのワークフローを持つ自分だけのagentを作るための、コード向けframework。

OpenAI Agents SDK, LangGraph, CrewAI, Microsoft Agent Framework, Model Context Protocol

ロゴ・ブランディングにおすすめのAI

ロゴのアイデア、ブランドマーク、最初のブランドキットを素早く。

Recraft, Ideogram, Looka, Midjourney, ChatGPT Images

カスタマーサポートにおすすめのAI

AI agentとAIが下書きした返信で、顧客への対応を速く。

Intercom Fin, Zendesk AI, Help Scout, Claude, ChatGPT

WebスクレイピングにおすすめのAI

Webサイトを、アプリ、リサーチ、AIパイプライン向けのきれいなデータに。各サイトの利用規約とrobots.txtは守りましょう。

Firecrawl, Apify, Browserbase, Claude Code, Cursor

APIテストにおすすめのAI

リクエストを書き、テストを生成し、失敗するendpointをdebugする。

Postman, Cursor, Claude, ChatGPT, Bruno

メモ・ドキュメントにおすすめのAI

AIで、自分のメモやチームのドキュメントを書き、整理し、検索する。

Notion AI, Claude, ChatGPT, Superhuman Docs (formerly Coda), Mem
