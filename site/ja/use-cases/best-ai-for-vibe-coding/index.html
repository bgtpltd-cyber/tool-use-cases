ユースケース /

Vibe codingにおすすめのAI

説明して、動かして、調整する。ほぼ会話だけでソフトウェアを作れるツール。

スポンサー

あなたのツールをここに

この注目枠は、このユースケースに本当に合うツールを作っている方向けです。必ず明記し、編集部のおすすめとは常に分けて表示します。

メールでスポンサーを申し込む

おすすめ

  1. 1. Cursor

    AIファーストのコードエディタ（VS Codeのfork）。chat、inline edit、agent modeを搭載。

    ひとこと： 定番の選択肢。ちゃんとしたcodebaseとエディタは手元に残しつつ、ほとんどのコードはAIが書いてくれます。

  2. 2. Lovable

    promptからフルスタックのWebアプリを作れるビルダー。Supabase連携あり。

    ひとこと： アイデアから認証・データベースつきのWebアプリまで最速。セットアップは不要です。

  3. 3. v0

    VercelのAIアプリ/UIビルダー。promptからReact + Tailwindのアプリを生成。

    ひとこと： React/Next.jsで洗練されたUIを素早く作りたくて、Vercelにdeployするつもりならこれ。

  4. 4. Replit Agent

    ブラウザで使えるIDE。agentがpromptからアプリを作ってdeployまでしてくれる。

    ひとこと： ホスティングまで全部ブラウザで完結。すぐ共有できるプロトタイプに向いています。

  5. 5. Bolt.new

    StackBlitzの、ブラウザで動くprompt-to-appビルダー。

    ひとこと： Lovableに近いツール。フルスタックのデモを1つのタブで立ち上げるのに最適です。

  6. 6. Devin Desktop (formerly Windsurf)

    CognitionのAIコードエディタ（旧Windsurf）。本格的なIDEに加え、ローカルとクラウドのコーディングagentをまとめて動かす管理画面を備える。

    ひとこと： Cursorの代替。複数のagentを同時に動かす使い方が中心です。Cursorがしっくりこないなら試す価値あり。

おすすめは編集部の判断で、掲載料は受け取っていません。料金や機能はよく変わるので、各ツールの公式サイトで確認してください。
