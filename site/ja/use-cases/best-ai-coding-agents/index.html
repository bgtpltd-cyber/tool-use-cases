ユースケース /

おすすめのAI coding agent

タスクを受け取り、複数のファイルを編集し、コマンドを実行してdiffを返してくれるagent。

スポンサー

あなたのツールをここに

この注目枠は、このユースケースに本当に合うツールを作っている方向けです。必ず明記し、編集部のおすすめとは常に分けて表示します。

メールでスポンサーを申し込む

おすすめ

  1. 1. Claude Code

    Anthropicの、ターミナルで動くagentic codingツール。

    ひとこと： ターミナルから複数ファイルにまたがる変更をこなすのが得意。本格的なagentic作業で人気の1つです。

  2. 2. Cursor

    AIファーストのコードエディタ（VS Codeのfork）。chat、inline edit、agent modeを搭載。

    ひとこと： フル機能のエディタの中で動くagent mode。変更を1つずつ目で見てレビューできます。

  3. 3. OpenAI Codex

    OpenAIのcoding agent。クラウド上やCLIからリポジトリで作業する。

    ひとこと： タスクを渡してクラウドで並列に走らせ、できあがったPRをレビューする使い方。

  4. 4. GitHub Copilot

    VS Code、JetBrains、GitHubに組み込まれたAIペアプログラマー。

    ひとこと： Copilotのcoding agentはGitHubのissueから作業します。チームがGitHub中心なら自然にハマります。

  5. 5. Devin

    Cognitionの自律型ソフトウェアエンジニアリングagent。

    ひとこと： チケットを最初から最後まで丸ごと任せる前提の設計。高めで、チーム向けです。

  6. 6. OpenCode

    ターミナル、デスクトップ、IDEで使えるオープンソース（MIT）のコーディングagent。ローカルモデルを含む75以上のモデルプロバイダに対応。

    ひとこと： 無料・オープンソースで開発も活発。ローカルを含む好きなモデルや、手持ちのClaude・ChatGPT・Copilotのプランで使えます。

おすすめは編集部の判断で、掲載料は受け取っていません。料金や機能はよく変わるので、各ツールの公式サイトで確認してください。
