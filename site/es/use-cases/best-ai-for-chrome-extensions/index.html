Mejor IA para crear extensiones de Chrome

Pasa de 'debería haber un botón para esto' a una extensión de navegador que funciona.

Última revisión: 22 de octubre de 2026 · Publicado por Lali Publications. Recomendaciones investigadas por nuestro editor de IA y verificadas en el sitio oficial de cada herramienta. Cómo elegimos

Nuestras recomendaciones

  1. 1. Cursor

    Editor de código pensado para la IA (un fork de VS Code), con chat, ediciones inline y modo agente.

    Veredicto: Opción n.º 1: genera el manifest, los scripts y el popup, y corrige errores en contexto mientras recargas y pruebas.

    Precio: Plan gratuito con uso limitado del agente. Plus (8 US$/mes) solo usa los modelos propios de Cursor (Grok, Composer); Premium (30 US$/mes) añade agentes en la nube y modelos Claude/GPT cobrados a precio de lista de la API. Se vende dentro de The X Subscription desde oct. de 2026.

  2. 2. Claude Code

    La herramienta de programación agéntica de Anthropic que funciona en la terminal.

    Veredicto: Excelente para crear la estructura base de toda la extensión e iterar sobre los problemas de permisos de Manifest V3.

    Precio: Incluido en Claude Pro (20 US$/mes, o 17 US$/mes en anual) y en Max (desde 100 US$/mes). No está en el plan gratuito.

  3. 3. ChatGPT

    El asistente de IA de uso general de OpenAI, con chat, imágenes, voz y búsqueda.

    Veredicto: Sirve para una extensión pequeña de un solo archivo. Revisa que use Manifest V3, porque hay ejemplos antiguos por todas partes.

    Precio: Plan gratuito. Planes de pago: Go, Plus (20 US$/mes) y Pro.

  4. 4. WXT

    Framework open source basado en Vite para crear extensiones de navegador multiplataforma en TypeScript.

    Veredicto: No es una herramienta de IA, pero combina bien con una: un framework basado en Vite, con mantenimiento activo, que elimina el boilerplate de las extensiones.

  5. 5. GitHub Copilot

    Asistente de programación en pareja con IA, integrado en VS Code, los IDE de JetBrains y GitHub.

    Veredicto: Buen autocompletado para las APIs de Chrome si prefieres escribir el código tú mismo.

    Precio: Plan gratuito con chat y agente limitados. Pro: 10 US$/mes; Pro+: 39 US$/mes; Max: 100 US$/mes.

Precios comprobados el 22 de octubre de 2026 en la página oficial de precios de cada herramienta. Cambian a menudo; manda siempre la página oficial.

Las recomendaciones son editoriales y nadie paga por ellas. Los precios y las funciones cambian a menudo: consulta el sitio oficial de cada herramienta.
