Use cases

কাজটা বেছে নিন। কোন টুলগুলো ট্রাই করার মতো আর কেন, আমরা বলে দেব।

Vibe coding-এর জন্য সেরা AI

বলুন, চালান, ঠিকঠাক করুন। এমন টুলস যা দিয়ে বেশিরভাগটা কথা বলেই সফটওয়্যার বানানো যায়।

Cursor, Lovable, v0, Replit Agent, Bolt.new, Devin Desktop (formerly Windsurf)

সেরা AI coding agents

এমন agents যারা টাস্ক নেয়, একাধিক ফাইল এডিট করে, commands চালায় আর একটা diff নিয়ে ফেরে।

Claude Code, Cursor, OpenAI Codex, GitHub Copilot, Devin, OpenCode

ভাঙা কোড আর errors ঠিক করার সেরা AI

Stack trace পেস্ট করুন, fix পান। এমন টুলস যারা শুধু কোড বানাতে নয়, debugging-এও ভালো।

Claude, Cursor, ChatGPT, GitHub Copilot, Sentry (Seer), Claude Code

গেম prototyping-এর সেরা AI

খেলার মতো একটা আইডিয়া দ্রুত স্ক্রিনে আনুন — কোড, art, 3D আর মিউজিক।

Rosebud AI, Cursor, Scenario, Meshy, Suno, ElevenLabs

ভিডিও আর YouTube-এর সেরা AI

Footage বানান, তাড়াতাড়ি এডিট করুন, voice দিন আর Shorts কাটুন।

Descript, Runway, Google Veo, ElevenLabs, OpusClip, CapCut, HeyGen

সেরা AI writing assistants

Drafting, editing আর rewriting — docs, blog posts, READMEs, emails।

Claude, ChatGPT, Notion AI, Grammarly, Gemini

রিসার্চের জন্য সেরা AI

Sources খুঁজুন, পড়ুন আর summarize করুন — এমন citations সহ যা যাচাই করা যায়।

Perplexity, Gemini Notebook (formerly NotebookLM), ChatGPT, Gemini, Elicit, Grok

Image generation-এর সেরা AI

Thumbnails, concept art, mockups, memes।

Midjourney, ChatGPT Images, Ideogram, FLUX (Black Forest Labs), Adobe Firefly, Stable Diffusion

লোকালি AI চালানোর সেরা টুলস

নিজের মেশিনে প্রাইভেট AI, চালাতে কোনো খরচ নেই।

Ollama, DeepSeek, OpenCode, Stable Diffusion

Automation workflows-এর সেরা AI

নিজের অ্যাপগুলো জুড়ে দিন আর একঘেয়ে ধাপগুলো AI-কে সামলাতে দিন — triggers, agents আর glue code।

n8n, Make, Zapier, Claude Code, Manus

Landing pages-এর সেরা AI

এক বিকেলেই আইডিয়া থেকে live, দেখতে ভালো একটা landing page।

Lovable, Framer, v0, Bolt.new, Cursor

UI design-এর সেরা AI

Prompt বা sketch থেকে screens, তারপর এমন কিছু যা আপনি বানাতে পারবেন।

Figma, v0, Google Stitch, Uizard, Lovable

সেরা AI voice আর text-to-speech

মাইক ছাড়াই voiceovers, narration, cloned voices আর অ্যাপের speech।

ElevenLabs, OpenAI Text-to-Speech, Descript, HeyGen

মিউজিকের জন্য সেরা AI

Prompt থেকে গান, soundtracks আর background মিউজিক।

Suno, Lyria in Gemini, AIVA, ElevenLabs

SEO content-এর সেরা AI

Rank করতে পারে এমন পেজের রিসার্চ, outline আর লেখা — AI-এর আবর্জনা publish না করে।

Claude, Surfer, Clearscope, Perplexity, ChatGPT

Sales emails-এর সেরা AI

আরও ভালো cold আর follow-up emails লিখুন — personal, ছোট, আর দেখে বোঝা যাবে না যে AI লিখেছে।

Claude, ChatGPT, Lavender, Perplexity, Grammarly

ডেটা আর spreadsheets-এর সেরা AI

CSVs analyze করুন, formulas লিখুন আর charts বানান — সহজ ভাষায় জিজ্ঞেস করেই।

ChatGPT, Claude, Julius AI, Microsoft 365 Copilot (Excel), Gemini

Presentations-এর সেরা AI

Outline থেকে মোটামুটি ভালো slide deck, তাড়াতাড়ি।

Gamma, Beautiful.ai, Claude, ChatGPT, Microsoft 365 Copilot (PowerPoint)

3D assets-এর সেরা AI

Text বা images থেকে props, characters আর models বানান।

Meshy, Tripo, Hyper3D Rodin, Scenario, Stable Diffusion

মিটিং notes-এর সেরা AI

কল রেকর্ড, transcribe আর summarize করুন, যাতে কাউকে notes নিতে না হয়।

Fireflies.ai, Otter.ai, Grain, Notion AI, Claude

Chatbots আর RAG-এর সেরা AI

এমন অ্যাসিস্ট্যান্ট বানান যা আপনার নিজের docs থেকে উত্তর দেয় — no-code থেকে custom কোড পর্যন্ত।

Claude, ChatGPT, LlamaIndex, LangChain, Cursor, Gemini Notebook (formerly NotebookLM)

AI দিয়ে বানানো অ্যাপের সেরা hosting

আপনার AI টুলস এইমাত্র যে অ্যাপ বানাল, সেটা কোথায় ship করবেন। এগুলো AI টুল নয়, hosting প্ল্যাটফর্ম — AI-এর সাহায্যে যারা বানান তাদের সঙ্গে কতটা মানানসই, সেই হিসেবে বাছাই।

Vercel, Netlify, Railway, Fly.io, Replit Agent

Chrome extensions বানানোর সেরা AI

'এটার জন্য একটা বোতাম থাকা উচিত' থেকে চালু browser extension পর্যন্ত।

Cursor, Claude Code, ChatGPT, WXT, GitHub Copilot

YouTube thumbnails আর packaging-এর সেরা AI

Thumbnails, titles আর সেই hook যা ক্লিক এনে দেয়।

Ideogram, ChatGPT Images, Canva, Midjourney, Claude

সেরা AI agent frameworks

Tools, memory আর multi-step workflows সহ নিজের agents বানানোর code frameworks।

OpenAI Agents SDK, LangGraph, CrewAI, Microsoft Agent Framework, Model Context Protocol

Logos আর branding-এর সেরা AI

Logo আইডিয়া, brand marks আর শুরুর brand kit, তাড়াতাড়ি।

Recraft, Ideogram, Looka, Midjourney, ChatGPT Images

Customer support-এর সেরা AI

AI agents আর AI-এর লেখা replies দিয়ে কাস্টমারদের আরও তাড়াতাড়ি উত্তর দিন।

Intercom Fin, Zendesk AI, Help Scout, Claude, ChatGPT

Web scraping-এর সেরা AI

ওয়েবসাইটগুলোকে অ্যাপ, রিসার্চ আর AI pipelines-এর জন্য পরিষ্কার ডেটায় বদলান। প্রতিটা সাইটের terms আর robots.txt মেনে চলুন।

Firecrawl, Apify, Browserbase, Claude Code, Cursor

API testing-এর সেরা AI

Requests লিখুন, tests বানান আর ফেল করা endpoints debug করুন।

Postman, Cursor, Claude, ChatGPT, Bruno

Notes আর docs-এর সেরা AI

AI দিয়ে নিজের notes আর টিম docs লিখুন, গোছান আর সার্চ করুন।

Notion AI, Claude, ChatGPT, Superhuman Docs (formerly Coda), Mem
