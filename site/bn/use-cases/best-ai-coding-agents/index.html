সেরা AI coding agents

এমন agents যারা টাস্ক নেয়, একাধিক ফাইল এডিট করে, commands চালায় আর একটা diff নিয়ে ফেরে।

আপনার টুল এখানে

এই ফিচার্ড স্লটটা সেইসব টুল নির্মাতাদের জন্য, যাদের টুল এই use case-এ সত্যিই মানানসই। সবসময় পরিষ্কারভাবে লেবেল করা থাকে এবং আমাদের বাছাই থেকে আলাদা রাখা হয়।

স্পনসর করতে ইমেল করুন

আমাদের বাছাই

  1. 1. Claude Code

    Anthropic-এর terminal-এ চলা agentic coding টুল।

    আমাদের মত: Terminal থেকে multi-file পরিবর্তনে দুর্দান্ত; বড় agentic কাজের জন্য অনেকেরই ফেভারিট।

  2. 2. Cursor

    AI-first কোড এডিটর (VS Code-এর fork), যাতে chat, inline edits আর agent mode আছে।

    আমাদের মত: পুরো এডিটরের ভেতরে agent mode, তাই প্রতিটা পরিবর্তন চোখে দেখে রিভিউ করতে পারবেন।

  3. 3. OpenAI Codex

    OpenAI-এর coding agent, যা cloud-এ বা CLI থেকে আপনার repos-এ কাজ করে।

    আমাদের মত: টাস্কগুলো cloud-এ parallel চালাতে দিয়ে দিন, তারপর তৈরি হওয়া PRs রিভিউ করুন।

  4. 4. GitHub Copilot

    AI pair programmer, VS Code, JetBrains আর GitHub-এ বিল্ট-ইন।

    আমাদের মত: Copilot-এর coding agent GitHub issues থেকে কাজ করে — আপনার টিম যদি GitHub-এই থাকে তাহলে একদম মানানসই।

  5. 5. Devin

    Cognition-এর autonomous software engineering agent।

    আমাদের মত: পুরো tickets শুরু থেকে শেষ পর্যন্ত দিয়ে দেওয়ার জন্য বানানো; দামি, টিমের জন্য।

  6. 6. Aider

    Terminal-এ open-source AI pair programming, git বোঝে।

    আমাদের মত: ফ্রি, open-source, নিজের পছন্দের model ব্যবহার করুন; প্রতিটা পরিবর্তনের পরিষ্কার git commit করে।

এই বাছাই আমাদের নিজেদের, এর জন্য কেউ টাকা দেয়নি। দাম আর ফিচার প্রায়ই বদলায় — প্রতিটা টুলের অফিশিয়াল সাইট দেখে নিন।
