নতুন লঞ্চ ও ট্রেন্ডিং

গত ছয় সপ্তাহের AI টুল লঞ্চ আর বড় আপডেট, যেগুলো builders-দের কাজে লাগে। প্রতিটির সঙ্গে তারিখ, অফিসিয়াল ঘোষণার লিংক আর কোন use case-এ এটা মানানসই, সেটা দেওয়া আছে।

সর্বশেষ আপডেট: 26 অক্টোবর, 2026

23 অক্টোবর

Replit Monitoring Agent

Replit-এর Agent এখন published app-এর alerts background-এ নজরে রাখে, production-এর সমস্যা খতিয়ে দেখে আর একটা fix test করে। fix আপনি নিজে review করে publish করেন, যদি না experimental Auto-republish setting চালু করেন।

Use case: ভাঙা কোড আর errors ঠিক করার সেরা AI · সূত্র

20 অক্টোবর

Lovable: creates your Supabase project

Lovable এখন backend ছাড়া app-এর জন্য Supabase project তৈরি করে সেটা জুড়ে দেয়। organization আর region আপনি বাছেন (region পরে বদলানো যায় না), আর Supabase সেই project-এর বিল আপনার নিজের account-এ পাঠায়।

Use case: Vibe coding-এর জন্য সেরা AI · সূত্র

20 অক্টোবর

Mistral Voxtral 3

Mistral-এর নতুন speech-to-text আর text-to-speech models, সঙ্গে ফোন ও ওয়েবে real-time voice agents বানানোর SDK। Mistral-এর API (EU-hosted অপশনসহ) দিয়ে বা self-hosted।

Use case: সেরা AI voice আর text-to-speech · সূত্র

15 অক্টোবর

Kling 4.0

Kuaishou-র নতুন ভিডিও model: এক পাসে 30 সেকেন্ড পর্যন্ত clips, দ্রুত মুভমেন্ট আর ক্যামেরা মুভে বেশি স্থিরতা, আর প্রতি কাজে 15টা পর্যন্ত reference assets ও 10টা keyframes।

Use case: ভিডিও আর YouTube-এর সেরা AI · সূত্র

15 অক্টোবর

Meta Muse Spark Open

Meta-র open-weight model, coding আর agent-এর কাজের জন্য (816B parameters, 42B active, 1M-token context)। Meta এটা দুটো Mac Studio-তে চালায়; বেশিরভাগ মানুষের জন্য hosted APIs-ই সহজ পথ।

Use case: লোকালি AI চালানোর সেরা টুলস · সূত্র

7 অক্টোবর

Claude Haiku 5.5

Anthropic-এর সবচেয়ে সস্তা আর দ্রুত model, বেশি ভলিউমের কাজের জন্য তৈরি: support bots, summaries আর coding subagents। Anthropic বলছে, এটা চালাতে Haiku 4.5-এর চেয়ে প্রায় 75% কম খরচ।

Use case: Chatbots আর RAG-এর সেরা AI · সূত্র

6 অক্টোবর

Nano Banana 2.1 (Google)

Google-এর আপডেটেড image generation আর editing model: আরও ভালো edits, চরিত্রে বেশি consistency আর ছবিতে পরিষ্কার লেখা। Gemini অ্যাপ, AI Studio, Gemini API, Flow আর Stitch-এ পাওয়া যায়।

Use case: Image generation-এর সেরা AI · সূত্র

1 অক্টোবর

GitHub Copilot dynamic workflows

Multi-agent কাজ code-এ সাজিয়ে নিন (parallel steps, একে অপরকে যাচাই করা subagents, রিভিউয়ের জন্য checkpoints) — Copilot CLI, Copilot অ্যাপ আর Copilot SDK-তে। Public preview, সব plan-এ।

Use case: সেরা AI coding agents · সূত্র

30 সেপ্টেম্বর

HeyGen Video

HeyGen-এর প্রথম general-purpose ভিডিও model: টেক্সট, ছবি বা reference media থেকে 5 থেকে 15 সেকেন্ডের clips, যেখানে সংলাপ আর শব্দ একসঙ্গে তৈরি হয়। HeyGen API দিয়ে পাওয়া যায়।

Use case: ভিডিও আর YouTube-এর সেরা AI · সূত্র

29 সেপ্টেম্বর

GPT-6.1 Sol

OpenAI DevDay-তে আসা GPT-6 Sol-এর আপগ্রেড, যার ফোকাস agentic coding, computer use আর পেশাদার কাজ। OpenAI বলছে, অনেক কম দামে এটা GPT-6 Astra-র কাছাকাছি পৌঁছায়।

Use case: সেরা AI coding agents · সূত্র

29 সেপ্টেম্বর

OpenAI Agents API: computer use

Agents API এখন computer use দিয়ে software চালাতে পারে, আর Codex-এর multi-agent ফিচার, tool search ও context compaction আপনার অ্যাপে নিয়ে আসে। Infrastructure চালায় OpenAI।

Use case: সেরা AI agent frameworks · সূত্র

28 সেপ্টেম্বর

Claude Sonnet 5.5

Anthropic-এর দ্রুত আর সস্তা Sonnet, নির্দিষ্ট পরিসরের রোজকার কাজ আর bug fixing-এ সবচেয়ে ভালো। Sonnet 5-এর চেয়ে 30%+ দ্রুত, একই $2/$10 প্রতি million tokens দামে।

Use case: ভাঙা কোড আর errors ঠিক করার সেরা AI · সূত্র

24 সেপ্টেম্বর

Lovable: free chat

Lovable-এর সঙ্গে chat এখন রোজকার free সীমার মধ্যে বিনামূল্যে: features প্ল্যান করুন, অ্যাপের code আর database নিয়ে প্রশ্ন করুন বা লঞ্চের লেখা ড্রাফট করুন। Build করতে এখনও credits লাগে।

Use case: Vibe coding-এর জন্য সেরা AI · সূত্র

10 সেপ্টেম্বর

Cursor Projects

কোনো feature বা migration-এর মতো বড় কাজের জন্য beta: একটা coordinator agent cloud-এ চলে, কাজ প্ল্যান করে, অনেক subagents-কে ভাগ করে দেয় আর সময়ের সঙ্গে shared context ধরে রাখে।

Use case: সেরা AI coding agents · সূত্র

আগের লঞ্চ

এই আপডেটের আগে আমরা যে লঞ্চগুলো দেখিয়েছিলাম। এগুলো আর নতুন নয়, তবে জেনে রাখার মতো।

  • Claude Code — Anthropic-এর terminal coding agent — সবচেয়ে বেশি আলোচিত dev টুলসের একটা।
  • OpenAI Codex — OpenAI-এর নতুন করে লঞ্চ করা Codex coding agent (cloud + CLI)।
  • Google Veo — Google-এর ভিডিও model, এখন synced audio-ও বানায়।
  • Manus — Autonomous general agent, multi-step কাজের জন্য যা ভাইরাল হয়েছিল।
  • Lovable — দ্রুত বেড়ে চলা prompt-to-app builder।
  • Gemini Notebook (formerly NotebookLM) — Audio Overviews research notes-কে podcasts-এ বদলে দিয়েছে।
  • Kling — AI ভিডিও generation-এ জোরালো প্রতিযোগী।
  • DeepSeek — Open-weight reasoning models, যা pricing-এ নাড়া দিয়েছে।
  • Model Context Protocol — সেই open protocol, যা এখন বেশিরভাগ agent টুলস tools access-এর জন্য সাপোর্ট করে।
  • Devin Desktop (formerly Windsurf) — Agentic এডিটর, যা সরাসরি Cursor-এর সঙ্গে টক্কর দেয়।
