Which AI tool for which job.

Tool Use Cases is a directory of AI tools organized by the job you're trying to do — for vibe coders, builders, and anyone shipping with AI.

Use cases

New releases & trending

  • Mistral Voxtral 3 (Oct 20) — Mistral's new speech-to-text and text-to-speech models, plus a voice-agent SDK for real-time phone and web agents. Via Mistral's API (EU-hosted option) or self-hosted.
  • Kling 4.0 (Oct 15) — Kuaishou's new video model: clips up to 30 seconds in one pass, steadier fast motion and camera moves, and up to 15 reference assets and 10 keyframes per job.
  • Meta Muse Spark Open (Oct 15) — Meta's open-weight model for coding and agent work (816B parameters, 42B active, 1M-token context). Meta runs it on two Mac Studios; for most people, hosted APIs are the practical way in.
  • Claude Haiku 5.5 (Oct 7) — Anthropic's cheapest, fastest model, built for high-volume work like support bots, summaries and coding subagents. Anthropic says it costs about 75% less to run than Haiku 4.5.
  • Nano Banana 2.1 (Google) (Oct 6) — Google's updated image generation and editing model, with better edits, character consistency and text in images. In the Gemini app, AI Studio, the Gemini API, Flow and Stitch.
