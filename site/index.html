Which AI tool for which job.

Tool Use Cases is a directory of AI tools organized by the job you're trying to do — for vibe coders, builders, and anyone shipping with AI.

Use cases

Best AI for vibe coding

Describe it, run it, tweak it. Tools that let you build software mostly by talking.

Cursor, Lovable, v0, Replit Agent, Bolt.new, Windsurf

Best AI coding agents

Agents that take a task, edit multiple files, run commands and come back with a diff.

Claude Code, Cursor, OpenAI Codex, GitHub Copilot, Devin, Aider

Best AI for fixing broken code and errors

Paste the stack trace, get a fix. Tools that are good at debugging, not just generating.

Claude, Cursor, ChatGPT, GitHub Copilot, Sentry (Seer), Claude Code

Best AI for game prototyping

Get a playable idea on screen fast — code, art, 3D and music.

Rosebud AI, Cursor, Scenario, Meshy, Suno, ElevenLabs

Best AI for video and YouTube

Generate footage, edit faster, voice it, and cut it into Shorts.

Descript, Runway, Google Veo, ElevenLabs, Opus Clip, CapCut, HeyGen

Best AI writing assistants

Drafting, editing and rewriting — docs, blog posts, READMEs, emails.

Claude, ChatGPT, Notion AI, Grammarly, Gemini

Best AI for research

Find sources, read them, and summarize — with citations you can check.

Perplexity, NotebookLM, ChatGPT, Gemini, Elicit, Grok

Best AI image generation

Thumbnails, concept art, mockups, memes.

Midjourney, ChatGPT Images, Ideogram, FLUX (Black Forest Labs), Adobe Firefly, Stable Diffusion

Best tools for running AI locally

Private, free-to-run AI on your own machine.

Ollama, DeepSeek, Aider, Stable Diffusion
