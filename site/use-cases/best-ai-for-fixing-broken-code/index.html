Our picks

  1. 1. Claude

    Anthropic's AI assistant, strong at long documents, writing and code.

    Verdict: Paste the error plus the relevant files; strong at reasoning about the actual root cause.

  2. 2. Cursor

    AI-first code editor (VS Code fork) with chat, inline edits and an agent mode.

    Verdict: Fixes in place with full project context — no copy-paste back and forth.

  3. 3. ChatGPT

    OpenAI's general-purpose AI assistant with chat, images, voice and search.

    Verdict: Good general debugger, and can run Python to reproduce issues.

  4. 4. GitHub Copilot

    AI pair programmer built into VS Code, JetBrains and GitHub.

    Verdict: 'Fix' and '/explain' right in the editor where the red squiggle is.

  5. 5. Sentry (Seer)

    Error monitoring with AI root-cause analysis and fix suggestions.

    Verdict: Catches errors in production and suggests fixes using real traces.

  6. 6. Claude Code

    Anthropic's terminal-based agentic coding tool.

    Verdict: Let it run the tests, read the failure, and iterate until green.

Picks are editorial and not paid. Pricing and features change often — check each official site.
