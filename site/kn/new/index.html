ಹೊಸ ಲಾಂಚ್‌ಗಳು, ಟ್ರೆಂಡಿಂಗ್

ಕಳೆದ ಆರು ವಾರಗಳಲ್ಲಿ ಬಂದ, builders ಗೆ ಮುಖ್ಯವಾದ AI ಟೂಲ್ ಲಾಂಚ್‌ಗಳು ಮತ್ತು ದೊಡ್ಡ ಅಪ್‌ಡೇಟ್‌ಗಳು. ಪ್ರತಿಯೊಂದಕ್ಕೂ ದಿನಾಂಕ, ಅಧಿಕೃತ ಘೋಷಣೆಯ ಲಿಂಕ್ ಮತ್ತು ಅದು ಹೊಂದುವ use case ಕೊಟ್ಟಿದ್ದೇವೆ.

ಕೊನೆಯ ಅಪ್‌ಡೇಟ್: ಅಕ್ಟೋಬರ್ 27, 2026

ಅಕ್ಟೋಬರ್ 27

Replit Cloud Agents for company codebases

Replit Cloud Agents ಈಗ ನಿಮ್ಮ ಕಂಪನಿಯ ಈಗಾಗಲೇ ಇರುವ GitHub ಅಥವಾ GitLab repos ಮೇಲೆ ಕೆಲಸ ಮಾಡುತ್ತವೆ. ತಂಡದ ಯಾರಾದರೂ ಬದಲಾವಣೆಯನ್ನು ವಿವರಿಸಿದರೆ, agent ಅದನ್ನು ಚಾಲನೆಯಲ್ಲಿರುವ app ನಲ್ಲಿ test ಮಾಡಿ, engineers review ಮಾಡಲು screenshots ಮತ್ತು video ಜೊತೆ pull request ತೆರೆಯುತ್ತದೆ. Pro ಮತ್ತು Enterprise plans ನಲ್ಲಿ.

Use case: ಬೆಸ್ಟ್ AI coding agents · ಮೂಲ

ಅಕ್ಟೋಬರ್ 26

GPT-6.1 Terra in GitHub Copilot

OpenAI ನ ಹೊಸ model ಈಗ GitHub Copilot ನಲ್ಲಿ ಎಲ್ಲರಿಗೂ ಲಭ್ಯವಿದೆ; ದಿನನಿತ್ಯದ agentic coding ಮತ್ತು terminal ಕೆಲಸಕ್ಕಾಗಿ ರೂಪಿಸಲಾಗಿದೆ, GPT-6.1 Sol ಗಿಂತ ಕಡಿಮೆ ವೆಚ್ಚದಲ್ಲಿ. Copilot Pro, Pro+, Max, Business ಮತ್ತು Enterprise ನಲ್ಲಿ, ಹಂತಹಂತವಾಗಿ rollout ಆಗುತ್ತಿದೆ.

Use case: ಬೆಸ್ಟ್ AI coding agents · ಮೂಲ

ಅಕ್ಟೋಬರ್ 23

Replit Monitoring Agent

Replit Agent ಈಗ published app ನ alerts ಅನ್ನು background ನಲ್ಲಿ ಗಮನಿಸಿ, production ಸಮಸ್ಯೆಗಳನ್ನು ಪರಿಶೀಲಿಸಿ ಒಂದು fix ಅನ್ನು test ಮಾಡುತ್ತದೆ. experimental Auto-republish setting ಆನ್ ಮಾಡದಿದ್ದರೆ fix ಅನ್ನು ನೀವೇ review ಮಾಡಿ publish ಮಾಡುತ್ತೀರಿ.

Use case: ಕೆಲಸ ಮಾಡದ ಕೋಡ್, errors ಸರಿಪಡಿಸಲು ಬೆಸ್ಟ್ AI · ಮೂಲ

ಅಕ್ಟೋಬರ್ 20

Cursor Agent SDK

ನಿಮ್ಮದೇ agent ಅನ್ನು ಒಂದು code folder ಆಗಿ ನಿರ್ಮಿಸಿ (prompt, typed tools, skills ಮತ್ತು MCP connections), evals ಮೂಲಕ test ಮಾಡಿ, Cursor ಅಥವಾ ನಿಮ್ಮ servers ನಲ್ಲಿ deploy ಮಾಡಿ. agents GitHub, GitLab, Bitbucket, Slack, webhook ಅಥವಾ cron events ಮೇಲೆ ಶುರುವಾಗಬಹುದು.

Use case: ಬೆಸ್ಟ್ AI agent frameworks · ಮೂಲ

ಅಕ್ಟೋಬರ್ 20

Lovable: creates your Supabase project

Lovable ಈಗ backend ಇಲ್ಲದ app ಗಾಗಿ Supabase project ರಚಿಸಿ ಅದನ್ನು ಜೋಡಿಸುತ್ತದೆ. organization ಮತ್ತು region ಅನ್ನು ನೀವೇ ಆರಿಸುತ್ತೀರಿ (region ಅನ್ನು ನಂತರ ಬದಲಾಯಿಸಲಾಗದು), ಮತ್ತು Supabase ಆ project ನ ಬಿಲ್ ಅನ್ನು ನಿಮ್ಮ ಸ್ವಂತ account ಗೆ ಹಾಕುತ್ತದೆ.

Use case: Vibe coding ಗೆ ಬೆಸ್ಟ್ AI · ಮೂಲ

ಅಕ್ಟೋಬರ್ 20

Mistral Voxtral 3

Mistral ನ ಹೊಸ speech-to-text ಮತ್ತು text-to-speech models, ಜೊತೆಗೆ ಫೋನ್ ಮತ್ತು ವೆಬ್‌ನಲ್ಲಿ real-time voice agents ಗಾಗಿ SDK. Mistral API (EU-hosted ಆಯ್ಕೆಯೊಂದಿಗೆ) ಮೂಲಕ ಅಥವಾ self-hosted.

Use case: ಬೆಸ್ಟ್ AI voice ಮತ್ತು text-to-speech · ಮೂಲ

ಅಕ್ಟೋಬರ್ 15

Kling 4.0

Kuaishou ನ ಹೊಸ ವಿಡಿಯೋ model: ಒಂದೇ ಪಾಸ್‌ನಲ್ಲಿ 30 ಸೆಕೆಂಡ್‌ವರೆಗಿನ clips, ವೇಗದ ಚಲನೆ ಮತ್ತು ಕ್ಯಾಮೆರಾ ಮೂವ್‌ಗಳಲ್ಲಿ ಹೆಚ್ಚು ಸ್ಥಿರತೆ, ಪ್ರತಿ ಕೆಲಸಕ್ಕೆ 15 ರವರೆಗೆ reference assets ಮತ್ತು 10 keyframes.

Use case: ವಿಡಿಯೋ ಮತ್ತು YouTube ಗೆ ಬೆಸ್ಟ್ AI · ಮೂಲ

ಅಕ್ಟೋಬರ್ 15

Meta Muse Spark Open

Coding ಮತ್ತು agent ಕೆಲಸಗಳಿಗಾಗಿ Meta ದ open-weight model (816B parameters, 42B active, 1M-token context). Meta ಇದನ್ನು ಎರಡು Mac Studios ಮೇಲೆ ಓಡಿಸುತ್ತದೆ; ಹೆಚ್ಚಿನವರಿಗೆ hosted APIs ಸುಲಭ ದಾರಿ.

Use case: AI ಅನ್ನು local ಆಗಿ ರನ್ ಮಾಡಲು ಬೆಸ್ಟ್ ಟೂಲ್‌ಗಳು · ಮೂಲ

ಅಕ್ಟೋಬರ್ 7

Claude Haiku 5.5

Anthropic ನ ಅತ್ಯಂತ ಅಗ್ಗದ, ಅತ್ಯಂತ ವೇಗದ model; support bots, summaries ಮತ್ತು coding subagents ನಂತಹ ಹೆಚ್ಚು ಪ್ರಮಾಣದ ಕೆಲಸಗಳಿಗಾಗಿ. Haiku 4.5 ಗಿಂತ ಓಡಿಸಲು ಸುಮಾರು 75% ಕಡಿಮೆ ಖರ್ಚು ಎಂದು Anthropic ಹೇಳುತ್ತದೆ.

Use case: Chatbots ಮತ್ತು RAG ಗೆ ಬೆಸ್ಟ್ AI · ಮೂಲ

ಅಕ್ಟೋಬರ್ 6

Nano Banana 2.1 (Google)

Google ನ ಅಪ್‌ಡೇಟ್ ಆದ image generation ಮತ್ತು editing model: ಉತ್ತಮ edits, ಪಾತ್ರಗಳಲ್ಲಿ ಹೆಚ್ಚು consistency ಮತ್ತು ಚಿತ್ರಗಳಲ್ಲಿ ಸ್ಪಷ್ಟ ಪಠ್ಯ. Gemini ಆ್ಯಪ್, AI Studio, Gemini API, Flow ಮತ್ತು Stitch ನಲ್ಲಿ ಲಭ್ಯ.

Use case: Image generation ಗೆ ಬೆಸ್ಟ್ AI · ಮೂಲ

HeyGen Video

Claude Sonnet 5.5

Anthropic ನ ವೇಗದ, ಅಗ್ಗದ Sonnet; ಸ್ಪಷ್ಟ ವ್ಯಾಪ್ತಿಯ ದಿನನಿತ್ಯದ ಕೆಲಸಗಳು ಮತ್ತು bug fixing ನಲ್ಲಿ ಬಲಿಷ್ಠ. Sonnet 5 ಗಿಂತ 30%+ ವೇಗ, ಅದೇ $2/$10 ಪ್ರತಿ million tokens ಬೆಲೆಗೆ.

ಹಿಂದಿನವು

ಈ ಅಪ್‌ಡೇಟ್‌ಗೆ ಮೊದಲು ನಾವು ತೋರಿಸಿದ್ದ ಲಾಂಚ್‌ಗಳು. ಇವು ಈಗ ಹೊಸದಲ್ಲ, ಆದರೆ ತಿಳಿದುಕೊಳ್ಳಲು ಯೋಗ್ಯ.

  • Claude Code — Anthropic ನ terminal coding agent — ಅತಿ ಹೆಚ್ಚು ಚರ್ಚೆಯಲ್ಲಿರುವ dev ಟೂಲ್‌ಗಳಲ್ಲಿ ಒಂದು.
  • OpenAI Codex — OpenAI ಮತ್ತೆ ಲಾಂಚ್ ಮಾಡಿದ Codex coding agent (cloud + CLI).
  • Google Veo — Google ನ ವಿಡಿಯೋ model, ಈಗ synced audio ಕೂಡ ತಯಾರಿಸುತ್ತದೆ.
  • Manus — Multi-step ಕೆಲಸಗಳಿಂದ viral ಆದ autonomous general agent.
  • Lovable — ವೇಗವಾಗಿ ಬೆಳೆಯುತ್ತಿರುವ prompt-to-app builder.
  • Gemini Notebook (formerly NotebookLM) — Audio Overviews ಮೂಲಕ research notes ಅನ್ನು podcasts ಆಗಿ ಬದಲಾಯಿಸಿತು.
  • Kling — AI ವಿಡಿಯೋ generation ನಲ್ಲಿ ಬಲಿಷ್ಠ ಸ್ಪರ್ಧಿ.
  • DeepSeek — Pricing ಅನ್ನೇ ಅಲ್ಲಾಡಿಸಿದ open-weight reasoning models.
  • Model Context Protocol — ಈಗ ಬಹುತೇಕ agent ಟೂಲ್‌ಗಳು tools access ಗಾಗಿ support ಮಾಡುವ open protocol.
  • Devin Desktop (formerly Windsurf) — Cursor ಗೆ ನೇರ ಪೈಪೋಟಿ ಕೊಡುವ agentic ಎಡಿಟರ್.
